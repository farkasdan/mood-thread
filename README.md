# Mood Thread

Swipe to how you feel, let go, and watch your day's mood curve grow.

A single-page web app, optimised for phones. Open it in the phone's browser and use "Add to Home Screen" to run it full screen; it keeps working offline after the first visit. Everything you log stays in your own browser.

This folder is the built site. It is generated by `build.py` from the Mood Thread source page; edit the source and rebuild rather than editing `index.html` by hand.
